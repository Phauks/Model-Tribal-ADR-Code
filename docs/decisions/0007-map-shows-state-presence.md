# 0007. Map shows state presence, not boundaries

- **Status:** Accepted; amended by [0027](0027-map-adds-census-land-areas.md), which adds a land areas view
- **Date:** 2026-11-20

## Context

Drawing territories risks error and dispute. Native Land Digital, which maps
territories, states that its "maps are not official sources" and removed maps
from nation pages because they "consistently led to misinformation"
([Native Land Digital](https://native-land.ca/about/what-we-map)).

## Decision

Each tribe profile lists the states where the nation has a presence, each with a
source. The map shades states and lists the nations present in each. No
boundaries are drawn.

## Consequences

Nations present in several states are listed in each. A later edition could add
points for courts or programs without drawing territory.

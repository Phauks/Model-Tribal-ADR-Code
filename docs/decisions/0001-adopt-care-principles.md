# 0001. Adopt the CARE Principles through a project charter

- **Status:** Accepted
- **Date:** 2026-11-20

## Context

The project gathers and publishes information about Native nations' dispute resolution practices, and its lead author is not Native American. Its legitimacy depends on how that knowledge is gathered, credited and controlled.

## Decision

Adopt the CARE Principles for Indigenous Data Governance (Collective benefit, Authority to control, Responsibility, Ethics) and state the project's commitments in [the charter](../charter.md).

## Consequences

- Every record about a nation carries a review status and sensitivity flags (see the [data model](../data-model.md)).
- A nation's request to correct, restrict or remove material about it wins.
- Restricted material is never published, exported, cached offline or served by an API.

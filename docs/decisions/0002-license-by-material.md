# 0002. License each kind of material differently

- **Status:** Accepted
- **Date:** 2026-11-20

## Context

The model provisions, the commentary, the data and the code have different users. A single license would either stop nations from enacting provisions freely or give away more than intended.

## Decision

| Material | License | Reasoning (project analysis, not legal advice) |
| --- | --- | --- |
| Model provisions and forms | CC0 1.0 | A nation's statute should not have to credit an outside author, and nations often use commercial code publishers; freely adoptable text is the purpose of a model |
| Commentary, illustrations, essays, docs | CC BY 4.0 | Keeps credit for authors while letting courts, schools and nonprofits reuse the work |
| Data (tribe profiles, source records, research logs) | CC BY 4.0 | Researchers can reuse with credit; charter limits still apply to restricted records |
| Code and schemas | MIT | Standard permissive software license; nothing in the code is culturally sensitive |
| Third-party, tribal and quoted material | Owners' terms | A license covers only what the licensor owns |
| Art | Each artist's agreement | Artists keep their rights |

Contributors certify their right to submit under these licenses with a [Developer Certificate of Origin](https://developercertificate.org/) sign-off.

## Consequences

The lead author may still sell the print edition, because these licenses restrict others, not the licensor; contributors' sign-off covers their text. See [LICENSE.md](../../LICENSE.md).

# Print edition

The build that turns `content/` into a print-ready PDF for Lulu will live
here. No build code exists yet. Version: see [version.txt](version.txt);
history: see [CHANGELOG.md](CHANGELOG.md).

The print version is separate from the content version: 1.0.0 will be the
1st Edition. Each PDF records the content version it was built from.
The PDF engine (Paged.js or Typst) is being chosen through a test build; see
[decision record 0005](../docs/decisions/0005-print-with-lulu.md).

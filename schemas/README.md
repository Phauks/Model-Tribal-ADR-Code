# Schemas

JSON Schemas (draft 2020-12) for every record type. See [docs/data-model.md](../docs/data-model.md) for what each record is for and how they connect. `examples/` holds one valid example per record schema; the tribe example uses a fictitious nation on purpose. The data file schemas below the record schemas have no example, because `scripts/validate_records.py` checks the files themselves.

| Schema | Validates |
| --- | --- |
| `common.schema.json` | Shared types used by the others |
| `source.schema.json` | `content/sources/<letter>/*.yaml` |
| `permission.schema.json` | The `rights` field of a source |
| `document-history.schema.json` | `content/documents/<letter>/*.yaml` (decision record 0018) |
| `tribe.schema.json` | `content/tribes/<letter>/*.yaml` |
| `provision.schema.json` | Front matter of `content/provisions/*.md` |
| `commentary.schema.json` | Front matter of `content/commentary/*.md` |
| `glossary.schema.json` | `content/glossary/*.yaml` |
| `method.schema.json` | `content/methods/*.yaml` |
| `variable.schema.json` | `content/variables/*.yaml` |
| `research-session.schema.json` | Front matter of `research/sessions/**/*.md` |
| `search-log.schema.json` | `research/search-logs/<topic>/<letter>/*.yaml` (decision record 0025) |
| `outreach-organization.schema.json` | `research/outreach/*.yaml` |
| `outreach-plan.schema.json` | The private outreach plan, kept outside git (decision record 0012) |
| `contribution-filing.schema.json` | Private contribution filings, kept outside git (decision record 0020; docs/contributions.md) |

Data files the website or the scripts read, generated by scripts and checked by `scripts/validate_records.py`. A CSV schema describes one row: every cell is text, an empty cell is left out before checking (so `required` means the cell may not be empty), and the file's header must list exactly the schema's properties.

| Schema | Validates |
| --- | --- |
| `tribal-law-provisions.schema.json` | Each row of `research/tribal-law/provisions.csv` |
| `compact-documents.schema.json` | Each row of `research/gaming/compact-documents.csv` |
| `compact-clauses.schema.json` | Each row of `research/gaming/compact-clauses.csv` |
| `compact-history-versions.schema.json` | Each row of `research/gaming/compact-history-versions.csv` |
| `compact-context.schema.json` | Each row of `research/gaming/compact-context.csv` |
| `tribal-court-opinions.schema.json` | Each row of `research/tribal-court-opinions/opinions.csv` (decision record 0047) |
| `supreme-court-courts.schema.json` | `content/supreme-court/courts.yaml` |
| `supreme-court-justices.schema.json` | `content/supreme-court/justices.yaml` |
